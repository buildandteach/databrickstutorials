# databrickstutorials

Build and Teach lessons for Databricks Free Edition.

The first track is **Associate fundamentals**. It starts with managed Delta tables and is the base later lessons can build toward Professional skills.

| Lesson | What you practice |
|---|---|
| [Build your first Delta Lake table](lessons/associate-fundamentals/01-first-delta-lake-table/) | Managed Delta tables, SQL and PySpark reads, `UPDATE`, `DESCRIBE HISTORY`, and time travel |

Open that folder's README for Free Edition setup. The notebook uses fictional sample customers and orders in the schema `byte_delta_demo_20261106`.
